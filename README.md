# Clínica Vida+

Sistema web desenvolvido para gerenciamento de pacientes de uma clínica.

O projeto foi desenvolvido com o objetivo de aplicar na prática conceitos de desenvolvimento web, programação em Python, banco de dados e construção de interfaces.

## Tecnologias utilizadas

- Python
- Flask
- HTML5
- CSS3
- SQLite
- Git
- GitHub

## Funcionalidades

- Cadastro de pacientes
- Listagem de pacientes
- Busca de pacientes
- Visualização de estatísticas
- Cálculo da idade média dos pacientes
- Identificação do paciente mais novo e mais velho
- Validação de dados de entrada
- Armazenamento das informações em banco de dados
- Interface web para utilização do sistema

## Estrutura do projeto

- `app.py` — aplicação principal e rotas do sistema
- `database.py` — gerenciamento e operações do banco de dados
- `templates/` — páginas HTML da aplicação
- `static/` — arquivos de estilização e recursos estáticos
- `clinica.db` — banco de dados SQLite
- `requirements.txt` — dependências necessárias para execução

## Objetivo

Desenvolver uma aplicação web funcional para gerenciamento de pacientes, evoluindo um projeto inicialmente baseado em lógica de programação para uma solução com interface web e persistência de dados.

## Aprendizados

Durante o desenvolvimento deste projeto, foram aplicados conceitos de:

- Desenvolvimento Back-end com Python e Flask
- Desenvolvimento Front-end com HTML e CSS
- Integração entre Front-end e Back-end
- Criação e utilização de rotas
- Manipulação de formulários
- Persistência de dados com SQLite
- Validação e tratamento de dados
- Organização e estruturação de projetos
- Versionamento com Git e GitHub
